# 上海 AI 校招 JD 收集与标注协议

## 纳入标准

1. 来源为企业官方招聘站、官方校招站或企业控制的招聘系统页面；
2. 工作地点明确包含上海；
3. 岗位属于 AI、机器学习、大模型、NLP、搜索推荐、数据挖掘或数据科学；
4. 面向校园招聘、应届生、毕业生项目或明确毕业届次；
5. 页面能够复核岗位标题、地点，以及至少一项职责或要求。

## 排除标准

- 只有搜索引擎摘要，官方页面已无法访问；
- 仅来自聚合招聘网站或个人转载；
- 工作地点只写“全国”且无法确认上海岗位；
- 纯社会招聘或要求多年全职经验；
- 无法区分岗位事实与网站推荐内容。

## 结构化规则

- 只提取原文存在的信息，不根据公司或岗位名猜测技能；
- `required_skills` 只放明确要求，`preferred_skills` 只放“优先/加分”项；
- 无截止日期时保留空值；只有官方详情仍显示申请入口且当前校招届次明确覆盖目标人群时可标 `active`，否则写 `unknown`；
- 同一官方职位 URL 只保留一条；不同城市版本视为不同岗位；
- 保存抓取日期 `checked_at=2026-08-12` 和简短 `source_evidence`。

## 标注流程

1. 标注者先阅读匿名候选人画像，不查看系统分数；
2. 对每个“候选人—岗位”对给出 0–3 相关性；
3. 写一句理由，指出岗位方向、命中能力和主要缺口；
4. 第二名标注者独立完成相同任务；
5. 分歧大于 1 级时讨论裁决，并保留两份原始标签；
6. 计算加权 Cohen’s kappa 或等级相关性，随实验结果报告。

## 合规与维护

数据用于研究和演示，不自动投递、不绕过登录或验证码、不大规模爬取受限网站。定期复核官方 URL；页面消失时保留结构化记录并把状态改为 `unknown`，而不是继续宣称正在招聘。
