# 秋招雷达 AI｜8 页路演结构

1. 产品定位：上海 AI 校招的一站式可解释求职 Agent。
2. 问题：直接让大模型打分缺少稳定规则、证据和评测。
3. 产品闭环：解析确认、过滤排名、优化与面试训练。
4. 核心机制：六维加权评分，硬约束与语义信号分开。
5. 工程证据：21 项测试、四种格式、五个页面、36 条合成岗位。
6. 诚信约束：可直接修改与完成工作后才能加入严格区分。
7. 评测边界：展示五组结果，同时主动披露合成集限制。
8. 路线：绿色 GitHub 基线 → 真实评测 → Supabase 安全云端版。

目标时长 3–5 分钟。所有数字都应保留来源；不得把合成集结果描述为真实用户效果。
