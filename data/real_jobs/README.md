# 真实公开岗位数据

本目录只保存可从企业官方招聘页面复核的公开岗位。聚合招聘网站、转载公众号和搜索摘要只能用于发现线索，不能作为最终来源。

## 状态定义

- `active`：官方页面明确显示仍可申请，或有尚未到期的明确截止日期。
- `expired`：官方页面明确关闭，或截止日期早于检查日期。
- `unknown`：页面可访问但无法确认是否仍接受申请。默认不在推荐页显示为“正在招聘”。

每条岗位必须包含 `source_url`、`checked_at`、`status` 和 `source_evidence`。证据只保存核验地点、招聘类型和职责/要求所需的短片段，不复制整篇岗位页面。

## 相关性标注

针对三类匿名候选人画像使用 0–3 分：

- `3`：岗位方向与候选人的主要技能/项目高度一致；
- `2`：方向相关，存在可补强的少量技能；
- `1`：岗位领域相邻，但核心要求明显不匹配；
- `0`：不相关或存在地点/招聘类型硬冲突。

初始标签为单人规则辅助标注，必须保留 `annotator`、`rationale` 和 `labeled_at`。正式实验前应由第二名标注者独立复标并计算一致性。
